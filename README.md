# Game

いろいろなゲームを制作・公開していくためのリポジトリです。
小さなアイデアを形にしながら、遊べるゲームを少しずつ増やしていきます。

## ゲーム一覧

各ゲームの遊び方・実行方法は、個別のREADMEを参照してください。

| ゲーム名 | 概要 | 開発状況 | 遊び方・公開先 |
| --- | --- | --- | --- |
| 手とリス | リスが手をつなぐ落ち物パズル。スマホ全画面モード対応 | v0.3.0（実機確認前） | [遊び方・実行方法](games/drop-field/README.md) |
| AREA TRACE | 元祖Qixの仕組みを基準にした陣取りゲーム | 基準版 v0.1 | [遊ぶ](https://game-area-trace.nakatjp.chatgpt.site) / [README](games/area-trace/README.md) |

## 構成方針

ゲームごとにフォルダを分け、個別に開発・更新できる構成にします。
現在の構成は以下のとおりです。

```text
Game/
├── README.md              # リポジトリ全体の案内・ゲーム一覧
└── games/
    ├── drop-field/        # 「手とリス」落ち物パズル
    │   ├── README.md
    │   ├── index.html
    │   ├── engine.mjs
    │   ├── game.mjs
    │   └── tests/
    └── area-trace/        # 陣取りゲームの元祖再現基準版
        ├── README.md
        ├── index.html
        ├── style.css
        ├── engine.mjs
        ├── game.mjs
        └── tests/
```

使用する技術、対応端末、実行方法、公開方法は、ゲームごとに決めます。
共通の仕組みや素材は、必要になった段階で整理します。

## 制作方針

- まずは小さく遊べる形にして、試しながら改善します。
- 操作方法とルールが伝わりやすいゲームを目指します。
- 文字の読みやすさ、色以外での情報伝達、操作方法など、アクセシビリティにも配慮します。
- 外部の画像・音声・フォントなどを使う場合は、利用条件を確認し、必要なクレジットを記載します。

## ゲームを追加するとき

1. `games/<game-id>/` にゲームのファイルを配置します。
2. ゲームごとの `README.md` に、概要、ルール、操作方法、対応環境、実行・開発手順を記載します。
3. 動作確認を行い、確認した環境と既知の制限を記載します。
4. このREADMEのゲーム一覧を更新します。公開した場合は、公開先へのリンクも追加します。
