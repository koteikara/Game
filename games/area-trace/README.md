# AREA TRACE — 元祖再現基準版

AREA TRACE は、陣取りアクションゲームの元祖 *Qix* のゲームループを、独自の名称・描画・配色で検証するための試作です。まず基準となる遊びを再現し、実際に遊んだ差分から次のオリジナリティを決めます。

## 再現した基準

| 元祖の要素 | AREA TRACE の実装 |
|---|---|
| 外周から線を引いて領域を囲う | 40×52の離散グリッド上で、外周・獲得領域の縁から線を引く |
| 敵がいない側を獲得 | 線で分割された連結領域を調べ、敵が存在しない側を塗る |
| 75%でステージクリア | 獲得率75%以上で次のステージへ進む |
| Fast / Slow の2速度 | FASTは250点/%、SLOWは500点/% |
| Qix | 未獲得領域内を不規則に動き、未完成の線に触れるとミス |
| Sparx | 外周と獲得領域の境界を移動し、プレイヤーに触れるとミス |
| Fuse | 描画中に停止すると始点から線を追い、到達するとミス |
| Time Line | カウントが尽きるとSparxが2体増え、全体が高速化 |
| 2体のQixを分断 | 3面目以降に2体出現し、別領域に分けると即クリア・倍率上昇 |

## 意図的な簡略化

- 元祖の連続座標ではなく、領域判定を明確に検証できるグリッド方式です。
- 敵の動きは、複数の線分からなる独自のランダムアニメーションです。
- 1人用のみ。音源、デモプレイ、細かな得点ボーナスはまだありません。
- 名称・画面素材・配色・音源は元祖から流用していません。

## 操作

- 矢印キー: 移動
- Z + 矢印キー: FAST DRAW
- X + 矢印キー: SLOW DRAW
- P / Esc: 一時停止
- スマートフォン: 描画速度を選択し、方向ボタンを長押し

## 開発

静的ファイルとして配信できます。リポジトリ直下で次を実行し、`/games/area-trace/` を開きます。

```sh
python -m http.server 8000
```

ゲームロジックのテスト:

```sh
node --test games/area-trace/tests/*.test.mjs
```
