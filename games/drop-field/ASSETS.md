# リスの素材

ユーザー提供のリス画像をキャラクー・配色の参考にし、内蔵の画像生成機能で作成しました。元の添付画像は変更していません。

| ファイル | 内容 |
| --- | --- |
| `assets/squirrel-face.png` | 正面の顔・耳・頬の両手のみ。胴体・足・しっぽなし |
| `assets/squirrel-hands.png` | 左右から伸びて中央でつないだ手。縦の接続時は90度回転 |

どちらも256×256の透過PNGです。ゲームは同梱ファイルを読み込み、外部の画像生成APIを呼びません。

## 生成時の指定の要旨

- 顔：参考画像の茶色い輪郭、オレンジ色の顔、黒い縦長の目、赤い鼻、丸い耳を維持する。顔と頬の左右の小さな手だけを、正方形の透明背景に描く。小さい表示でも分かる簡潔なイラストにする。胴体・足・しっぽ・文字を入れない。
- 手：参考画像と同じ茶色・画風で、左右から伸びて中央でつなぐ短い腕と手だけを描く。正方形の透明背景に水平に配置する。顔・胴体・文字を入れない。

## 後処理

顔画像は生成時に透過が反映されず、市松模様がRGB画像に残ったため、ユーザーから未完了処理と反映の指示を受けて、コードで明るい無彩色の背景部分を透明化しました。リスの顔は描き直していません。ゲームの表示サイズに合わせて256×256に縮小し、RGBAのPNGとして保存しました。手の画像は生成時のアルファを保持して縮小しています。

確認済み：両素材の四隅は完全透明で、透明・不透明の両方の画素を含みます。盤面色に重ねた素材確認画像で、背景の市松模様が残っていないことを確認しました。
