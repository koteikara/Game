# DROP FIELD

積んで、そろえて、消していく、1人用の落ち物パズルです。バージョン：0.1.0。
テトリスを参考にした独自実装で、公式製品ではありません。既存ゲームのロゴ・画像・音声・コードは使用していません。

## 遊び方

- 10列×20行の盤面に、7種類のブロックが落ちてきます。
- 横一列をすき間なく埋めると、その列が消えます。
- 10列消すごとにレベルが上がり、落下が速くなります。
- 新しいブロックを出せない、または盤面上端を超えて固定されると終了です。
- 次の3個を表示します。盤面の枠線は現在のブロックの着地点です。
- 着地後は450msの操作猶予があります。移動・回転による猶予の延長は1個につき12回までです。

| 操作 | キー |
| --- | --- |
| 左右に移動 | ← / → |
| 右に90度回転 | ↑ または X |
| 左に90度回転 | Z |
| 1マス下げる | ↓ |
| 一気に落とす | Space |
| 一時停止・再開 | P または Esc |

画面上のボタンでも操作でき、左右・下は長押しに対応します。
キーボード操作はゲーム領域にフォーカスがあるときだけ有効です。盤面を選択すると操作できます。
別のタブ・アプリへの切り替え、またはゲーム領域からのフォーカス移動で自動停止します。
得点や進行状況は保存しません。ページの再読み込みでリセットされます。

## 得点

| 同時に消した列数 | 得点 |
| --- | --- |
| 1列 | 100 × レベル |
| 2列 | 300 × レベル |
| 3列 | 500 × レベル |
| 4列 | 800 × レベル |

手動落下は1マス1点、一気に落とす操作は1マス2点です。
列消去の得点には、レベルアップ前のレベルを適用します。

## 実行方法

ゲーム自体はHTML・CSS・JavaScript（ES Modules）のみで動きます。パッケージのインストールやビルドは不要です。
Python 3がある環境で、リポジトリのルートから起動します。

```sh
python -m http.server 8000
```

ブラウザーで `http://localhost:8000/games/drop-field/` を開きます。
`index.html` のダブルクリック（file://）ではなく、HTTPサーバーを使ってください。

## ファイル構成

- `index.html`：画面と遊び方
- `style.css`：PC・スマートフォン向けの表示
- `engine.mjs`：盤面・衝突・回転・落下・列消去・得点
- `game.mjs`：描画、キーボード・画面ボタン操作、自動停止
- `tests/engine.test.mjs`：ゲームルールの自動テスト

## テスト

Node.js 20以降を使い、リポジトリのルートから実行します。追加パッケージは不要です。

```sh
node --test games/drop-field/tests/engine.test.mjs
```

初版で18件のテストが通過しています。衝突、回転、1〜4列消去、得点、一時停止、終了、リセット、6,000操作のシミュレーションを確認しています。
ブラウザーでの表示・操作確認、スマートフォン実機での確認は未実施です。

## 対応環境と制限

- Canvas、ES Modules、Pointer Eventsに対応したChrome・Edge・Firefox・Safariを想定しています。最低対応バージョンは未検証です。
- ボタンの名前、フォーカス表示、ゲーム状況の読み上げを用意しています。
- 盤面はCanvasによる視覚表現です。スクリーンリーダーだけで盤面を把握して遊べる機能は未対応です。
- 回転補正は独自の簡易方式です。公式の回転システム（SRS）を再現していません。
- ホールド、対戦、音声、ランキング、セーブ機能はありません。
- 外部の素材・フォント・通信APIは使用していません。
